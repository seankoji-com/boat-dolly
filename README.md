# Boat Dolly

A LEGO-style build booklet and shopping trolley for an aluminium A-frame launching dolly, sized for a Sabot (or another small boat up to 80 kg).

**Open it:** https://cart.seankoji.com/

It's a single self-contained `index.html`: 44 illustrated steps with isometric drawings, 1:1 printable drilling templates, a hull-cradle you shape to your own boat, a loading guide, a load test, and a shopping list split by store (aluminium supplier, fastener shop, Bunnings).

## Budget

The parts come to about **$472 AUD** (November 2026 estimates), inside a $500 budget. The trolley shows a budget meter, and you can type in real prices as you get quotes. The biggest saving is buying all the 50 x 50 x 3 tube as one 6.5 m length and having the supplier cut it into the four pieces. Tools and drill bits aren't included.

## Before you build

- **Not load-tested.** The design came from a parts list and sketches. Run the load-test page before it carries a boat.
- **Prices are estimates,** not quotes. Check prices and stock with each store.
- **A grown-up does every saw, drill, knife, glue and flame step.**

## Print the templates

Open the Templates page, print at 100% (turn off "fit to page"), and check the 50 mm line on each template measures 50 mm.
